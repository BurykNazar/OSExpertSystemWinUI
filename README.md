# OS Expert System WinUI

Експертна система для вибору операційної системи. Предметна область — консультаційний вибір ОС для домашнього ПК, офісної станції, робочої станції розробника, сервера або пристрою Apple.

## Технології

- C#
- WinUI 3 / XAML
- .NET 8
- Windows App SDK
- продукційні правила з вагами

## Архітектура

```text
Models/      — структури предметної області
Services/    — база знань, механізм виведення, налаштування вікна
UI/          — спільні кольори та UI-палітра
MainWindow   — WinUI/XAML інтерфейс і сценарії взаємодії
Assets/      — іконка застосунку
```

## Запуск

Відкрити `OSExpertSystemWinUI.csproj` або solution у Visual Studio, обрати `Debug x64` і запустити проєкт.

## Призначення

Програма не замінює системного адміністратора, а моделює його консультаційну логіку: користувач описує умови використання, система зіставляє відповіді з правилами бази знань, накопичує бали для кожної ОС і формує рейтинг рекомендацій із поясненням.


## Примітка щодо запуску WinUI 3

Якщо під час запуску виникає `Class not registered (0x80040154)`, потрібно встановити Windows App SDK Runtime або оновити пакет Microsoft.WindowsAppSDK через NuGet. У цьому проєкті прибрано Bootstrap/SelfContained-параметри, які можуть викликати Fail Fast Exception у деяких конфігураціях Visual Studio.
